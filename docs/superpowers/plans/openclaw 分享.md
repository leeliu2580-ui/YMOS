## 如果你有多agent复合型的使用场景和工作流(OPC):
自媒体运营:自动抓取素材->生成文案->生成视频->自动发布->数据分析
量化基金:行情数据->技术指标->交易决策->自动交易->风险管理->投资组合管理

## 架构
1、自建美国/英国VPS，并搭建cc-gateway用来连claude
2、搭建sub2api用来连gpt和gemini
3、Mac Mini上用cc-gateway的URL来连接claude code。
4、日常和龙虾沟通首选discord，支持分频道和会话，对于主题分类和节省memory大有好处。
分析。可以用便宜模型比如gpt5.2来处理cron和heartbeat
5、openclaw里用gpt 5.4做主模型，处理大部分日常事务。opus 4.6用来处理复杂任务比如写代码、数据
6、openclaw使用claude有两种方式: 
(1) claude code里安装discord播件连接bot,并把这个bott加到discord群聊里。 
(2) 让openclaw的bot通过ACP方式调用claude code写代码。
两种方式都需要macmini上常开claude code，是以正常方式调用，所以不会被封。

# Agent配置
每个agent单独配置agent/soul/identity/skill等文件。
千万不要自己写，每个角色根据上面的工作流和角色分工，和主agent进行头脑风暴讨论来确定如何配置。
推荐女蜗skil这个插件可以蒸馏很多大佬的特质，作为agent的辅助配置补充。
# Memory配置
推荐用lancedb-pro这个插件
最重要的配置，直接决定agent的智商、记忆力和模型的日常开销。

# skills的配置
我自己几乎不使用任何别人的skills，全部采用自研的形式。外部skills一方面存在安全性问题，一方面接口和设计很乱，不符合我整体系统的架构设计。
我的工作流:发现一个好的skils->让BllGates认真审核源代码，评估安全性和功能性->如果安全性没问题，且功能是目前系统所欠缺的，则按照系统的同意架构标准整合进来.目前我的信息系统，有几十个数据源，但是提供了统一的RESTAPI给其他agent访问
