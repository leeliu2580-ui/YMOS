# YMOS 技能（Skills）总览

> 技能（Skills）是 AI 的"工具箱"——每当你需要完成特定类型的任务时，AI 会自动调用对应的 Skill，确保工作方式规范、一致、不遗漏关键步骤。
>
> **你不需要记住所有 Skill**：当你描述一个任务时，AI 会自动判断应该使用哪个 Skill。

---

## 📁 技能目录

### 一、通用 Skills（OpenClaw 系统级）

这些技能来自 `D:\0_workspace\openclaw\.agents\skills\`，可在任何项目中使用：

| 技能名称 | 中文名称 | 何时触发 | 适用场景 | 使用示例 |
|:---|:---|:---|:---|:---|
| `web-access` | 网页访问 | 需要联网操作时 | 搜索信息、访问需要登录的网站、抓取社交媒体（小红书/微博/推特）、读取动态渲染页面 | "帮我查一下英伟达最新财报"、"抓取这个网页的数据" |
| `systematic-debugging` | 系统调试 | 遇到 Bug / 测试失败 / 异常行为 | 任何技术问题，在提出修复方案之前必须先找到根本原因 | "程序报错了"、"测试失败了"、"这个功能不正常" |
| `test-driven-development` | 测试驱动开发（TDD） | 实现任何新功能或修复 Bug 时 | 先写测试再写代码，确保代码有测试保护 | "实现一个新增功能"、"修复这个 Bug" |

| `subagent-driven-development` | 子代理驱动开发 | 有实施计划，任务之间相互独立，在当前 session 执行 | 多个相互独立的任务需要同时处理，每个任务派一个子代理 | "帮我同时处理这几个独立任务" |

## 🚦 技能触发规则（优先级）

当你描述一个任务时，AI 会按以下优先级判断使用哪个 Skill：

```
第一步：判断是否需要联网
  → 需要 → web-access / grok-search / exa-search

第二步：判断任务类型
  → Bug/异常 → systematic-debugging
  → 新功能/修改 → brainstorming（硬门槛！）
  → 有计划要执行 → executing-plans / subagent-driven-development
  → 声称完成 → verification-before-completion

第三步：判断数据需求
  → A股数据 → tushare-data
  → 美股数据 → finnhub
  → 加密货币 → cmc-official
  → 长文本摘要 → summarize

第四步：判断内容创作
  → 生成图片 → openai-image-gen
  → 生成视频 → wan-image-video-generation-editting
  → 音视频转写 → openai-whisper
  → 视频抽帧 → video-frames
```

## ⚠️ 重要原则

1. **brainstorming 是硬门槛**：任何创意/功能工作，在动手之前必须先头脑风暴设计，不允许跳过
2. **systematic-debugging 先找根因**：遇到 Bug 不许直接猜原因，必须先系统性分析
3. **verification-before-completion**：声称"修好了"、"完成了"之前必须实际运行验证
4. **TDD 先写测试**：新功能开发必须先写失败的测试，再写实现代码
5. **YMOS 记忆自动运行**：`memory-lancedb-pro` 在后台自动捕获对话，无需手动触发
