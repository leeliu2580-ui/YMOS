# 官方信息跟踪 SOP

## 1. 触发暗号
- `看一下公告 [TICKER]`
- `调研一下 [TICKER]` (作为子流程)

## 2. 执行流程
1. 调用 `fetch_official_updates.py` 获取官方更新。
2. 筛选治理、博客和重要公告。

## 3. 报告模板
```markdown
# 官方信息跟踪 - [SYMBOL] - [YYYY-MM-DD]

## 1. 最新官方更新
[列出标题、日期、来源和链接]

## 2. 治理与提案
[如有，列出当前活跃提案及状态]

## 3. 重要进展
- **合作/产品**: [描述]
- **激励/解锁**: [描述]

## 4. 观察逻辑影响
[基于 P17，描述这些信息是否改变了之前的观察重点]
```

## 4. 注意事项
- 严禁编造公告内容。
- 必须包含原始链接以便核实。
