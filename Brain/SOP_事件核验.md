# 事件核验 SOP

## 1. 触发暗号
- `核验一下 [事件描述]`
- `帮我看看 [项目名] 这件事是真的假的`

## 2. 执行流程
1. 明确核验目标。
2. 调用 `fetch_official_updates.py` 和 `fetch_research_links.py` 收集证据。
3. 按照 `Brain/references/p19-event-verification.md` 划分证据等级。
4. 给出最终可信度判断。

## 3. 报告模板
```markdown
# 事件核验 - [PROJECT] - [YYYY-MM-DD]

## 1. 待核验事件
[描述用户提出的说法]

## 2. 当前可确认事实
- **事实 A**: [描述 + 来源]
- **事实 B**: [描述 + 来源]

## 3. 证据链条
| 证据描述 | 来源 | 等级 | 状态 |
|:---|:---|:---|:---|
| ... | ... | ... | [已确认/未确认/疑似] |

## 4. 核验结论
- **综合可信度**: [高 / 中 / 低 / 无法判断]
- **核心逻辑分析**: [为什么给出这个判断]

## 5. 对仓位的影响
[描述该事件是否改变了项目的基本面或持仓逻辑]
```

## 4. 注意事项
- 无法确认时必须诚实输出“不足以下结论”。
- 必须带证据链接。
