# P19 加密事件核验与取证框架

## 1. 核心目标
针对市场争议说法或重大异动，通过多源取证，给出可信度判断。

## 2. 证据等级划分
- **一级证据（硬事实）**：链上交易记录、合约状态、官方签名公告、治理提案结果。
- **二级证据（高可信）**：项目方官方博客/X、主流行情平台（DeFiLlama/CMC）数据。
- **三级证据（参考）**：主流媒体报道、知名 KOL 深度分析。
- **四级证据（噪音）**：电报群传闻、匿名推特爆料。

## 3. 核验流程
1. **拆解说法**：将事件拆解为可验证的原子事实。
2. **寻找一级/二级证据**：优先查链上和官方。
3. **交叉验证**：如果一级证据缺失，通过多个二级证据相互印证。
4. **确定性输出**：
   - `已确认`：有硬证据支撑。
   - `未确认`：证据链不完整。
   - `疑似`：有间接证据但无直接证据。

## 4. 输出纪律
- 禁止用“我觉得”替代证据。
- 若所有源都无法确认，必须输出“不足以下结论”。
- 必须保留证据原始链接。
