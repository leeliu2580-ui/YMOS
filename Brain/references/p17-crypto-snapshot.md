# P17 加密观察快照分析框架

## 1. 核心目标
从价格、TVL、官方信息、K 线数据中，提炼出该加密标的当前的基本面与情绪状态，为后续决策提供依据。

## 2. 观察优先级
1. **价格与 K 线**：市场的第一反应，决定了短期强弱。
2. **TVL**：DeFi 协议的生命线，反映了资金的真实去向。
3. **官方更新**：项目方的动作，决定了叙事的可持续性。
4. **相对强弱**：与 BTC/ETH 比较，判断该币种是否具有 Beta 之外的 Alpha。

## 3. 事实与解释分离
- **事实**：价格跌 5%，TVL 涨 10%，官方发布了治理提案。
- **解释**：价格下跌可能是大盘拖累，但 TVL 逆势上涨说明协议内生动力强，治理提案可能带来长期利好。

## 4. 信号冲突处理
- **价格涨 + TVL 跌**：可能是短期投机炒作，叙事领先于基本面，需谨慎。
- **价格跌 + TVL 涨**：可能是深度价值区间，资金在低位吸筹，适合关注。
- **价格横盘 + 官方密集更新**：可能在积蓄能量，等待叙事爆发。

## 5. 输出纪律
- 不得忽略缺失数据。
- 必须明确标记数据来源。
- 结论必须基于快照中的结构化数据。
