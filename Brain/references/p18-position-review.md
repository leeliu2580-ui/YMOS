# P18 加密仓位复盘框架

## 1. 核心目标
结合持仓成本、当前价值与市场现状，回答“这一单现在该怎么办”。

## 2. 复盘逻辑顺序
1. **算账**：当前盈亏是多少？仓位占比是否有变化？
2. **趋势核验**：当初买入的逻辑（趋势/事件/估值）是否还在？
3. **失效条件核验**：是否触及止损位？是否发生了破坏基本面的黑天鹅？
4. **前提条件核验**：继续持有需要满足哪些条件（如 BTC 稳住、TVL 创新高）？

## 3. 判断标准
- **继续持有**：盈亏比合理，核心逻辑未破坏，处于上升趋势或震荡区间。
- **减仓/清仓**：触及止损，或逻辑被证伪（如官方跑路、严重安全漏洞、TVL 归零式下跌）。
- **观察**：趋势不明朗，等待关键位突破或重要事件落地。

## 4. 重点输出
- **继续持有的前提**：例如“只要价格不破 1.5u 且 TVL 保持在 1B 以上”。
- **风险提示**：当前面临的最大变数。

## 5. 纪律约束
- 严禁因为“舍不得亏损”而修正逻辑。
- 事实（数据）必须领先于判断。
