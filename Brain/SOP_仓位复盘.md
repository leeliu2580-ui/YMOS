# 仓位复盘 SOP

## 1. 触发暗号
- `持有怎么看 [TICKER]`
- `持仓 [TICKER] 怎么看`

## 2. 执行流程
1. 读取 `持仓_状态机.md` 或标的文件夹下的 `买入卖出备忘录.md` 获取成本和仓位。
2. 调用 `fetch_crypto_prices.py` 等脚本获取最新快照。
3. 计算当前盈亏。
4. 调用 `Brain/references/p18-position-review.md` 进行复盘分析。

## 3. 报告模板
```markdown
# 仓位复盘 - [SYMBOL] - [YYYY-MM-DD]

## 1. 当前持仓状态
- **开仓均价**: $[COST]
- **当前市值**: $[VALUE]
- **累计盈亏**: $[PNL] ([PNL_PERCENT]%)

## 2. 核心逻辑核验
- **买入逻辑**: [引用原始买入理由]
- **逻辑现状**: [有效 / 部分受损 / 已失效]

## 3. 基本面与技术面摘要
- **价格/K线**: [描述]
- **TVL/数据**: [描述]
- **官方/事件**: [描述]

## 4. 结论与动作建议
- **当前判断**: [继续持有 / 减仓 / 止损 / 观察]
- **继续持有的前提**: [明确条件，如“不破支撑位 X”]
- **失效条件**: [触发即走的条件]
```

## 4. 纪律约束
- 必须包含真实盈亏数据。
- 严禁情绪化判断。
